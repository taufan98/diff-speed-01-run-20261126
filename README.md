A faster drop-in for make.fun's own makefun-diff 1.0.0: it returns exactly makefun-diff's patch for every input, in less CPU time. `solve.js` interns each distinct line to an integer id once, runs Myers's greedy search with make.fun's exact tie-break on one reused flat Int32Array (no per-cell allocation), and backtracks the stored V rows to recover the same edit script.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
